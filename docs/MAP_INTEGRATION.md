# 🗺️ 地图集成方案

## 概述

本方案为 Green Logistics AI 项目实现交互式地图可视化。

**技术选择：** React-Leaflet + OpenStreetMap（免费，无需 API key）

---

## 📁 新增文件

```
web/frontend/src/components/Map/
├── index.js              # 组件导出
├── MapContainer.jsx      # 地图主容器
├── LogisticsNodes.jsx    # 供应/需求点标记
├── VehicleLayer.jsx      # 车辆实时位置
├── RouteLayer.jsx        # 优化路线可视化

```

## 📡 API 接口

### GET /api/supply-points
返回供应点列表：
```json
[
  {
    "agent_id": "SUP001",
    "stock_tons": 15.0,
    "material_type": "mixed_waste",
    "location": { "lat": 57.7089, "lon": 14.1618 }
  }
]
```

### GET /api/fleet-snapshot
返回车队实时位置：
```json
{
  "timestamp": "2026-05-13T12:00:00",
  "vehicles": [
    {
      "vehicle_id": "VEH001",
      "status": "en_route",
      "latitude": 57.75,
      "longitude": 14.2,
      "battery_level": 85.5,
      "cargo_load": 12.5,
      "speed": 45.2,
      "carbon_emission_rate": 0.85
    }
  ]
}
```

### POST /api/optimize
返回优化结果（包含路线坐标）：
```json
{
  "optimization_id": "OPT0001",
  "route_optimization": {
    "routes": [
      {
        "vehicle_id": "VEH001",
        "waypoints": [
          { "lat": 57.7089, "lon": 14.1618, "type": "depot" },
          { "lat": 57.72, "lon": 14.18, "type": "pickup" },
          { "lat": 57.68, "lon": 14.15, "type": "delivery" }
        ],
        "distance_km": 45.2,
        "cost_sek": 1250.0,
        "co2_kg": 38.4
      }
    ],
    "total_co2_kg": 125.3,
    "total_cost_sek": 2450.0
  }
}
```

## 🏃 运行

### 1. 启动后端
```bash
cd green-logistics-ai
source venv/bin/activate
python -m web.backend.main
```

### 2. 启动前端
```bash
cd web/frontend
npm install
npm run dev
```

### 3. 访问
- 前端：http://localhost:5173
- 后端 API：http://localhost:8000/docs
